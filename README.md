# IMDB Movie Exploratory Data Analysis

CSPG730 Assignment 1 — Saeed Thabit (700049326). Analysis of 1,000 movies released between 2006 and 2016, covering data profiling, cleaning, scaling, and exploratory analysis.

## Files

- `CSPG730_FA26_A1_700049326_SaeedThabit.ipynb` — complete analysis and saved results.
- `data/imdb_movie_dataset.csv` — original dataset (unchanged).
- `data/imdb_cleaned.csv` — cleaned dataset, regenerated by the notebook.
- `requirements.txt` — Python dependencies.
- `assets/CIT_Logo.jpg` — college logo; the first cell uses this local file or displays it from GitHub if missing.

- `output/pdf/CSPG730_FA26_A1_700049326_SaeedThabit.pdf` — printable notebook with code, results, and charts.

## Run locally

Use Python 3.12. From a terminal:

```bash
git clone https://github.com/SaeedAlbarhami/CSPG730-IMDB-EDA.git
cd CSPG730-IMDB-EDA
python -m pip install -r requirements.txt
python -m notebook
```

Open the notebook, select **Kernel → Restart & Run All**, and run from the project folder containing `data/`.

## Run in Google Colab

[Open in Google Colab](https://colab.research.google.com/drive/11gFMitot8_iTQSB2DfHgg0diwHXKbRWF?usp=sharing) · [GitHub repository](https://github.com/SaeedAlbarhami/CSPG730-IMDB-EDA)

Open the notebook through **File → Open notebook → GitHub** using the repository URL, then select **Runtime → Run all**. The notebook automatically reads the raw CSV from GitHub when `data/imdb_movie_dataset.csv` is unavailable locally; no repository clone or manual upload is needed. The CSV must first be published in the public GitHub repository.

If a dependency is missing, run `%pip install pandas numpy matplotlib seaborn scipy scikit-learn` in a separate cell, then restart the runtime and run all cells.

The cleaned CSV is saved to `data/imdb_cleaned.csv`. Download it before ending the Colab runtime if you need a local copy.

## Analysis notes

All 1,000 movies are retained. Missing Revenue and Metascore values are median-filled and flagged; their EDA uses observed values only. Original attributes are preserved alongside derived and scaled attributes. Findings describe this sample and do not establish causation. Package versions appear in the final cell.
